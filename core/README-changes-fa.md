# تغییرات این نسخه

## اجرا
```
python manage.py migrate      # مایگریشن‌های جدید (برچسب‌های فارسی + مدل‌های جدید)
```

## پنل داشبورد (/dashboard/)
- **خرید با دیجی‌کالا (BWDK):** لیست با فیلتر، صفحه‌ی جزئیات، Verify، بازگشت وجه، همگام‌سازی.
- **دیجی‌فای و ترب:** آدرس فیدها و وضعیت اتصال (بدون نمایش کلیدها).
- **مگا منو:** لیست/افزودن چندبرندی/ویرایش/حذف.
- بنرها، سوالات متداول، پرسش و پاسخ محصولات، تنظیمات سایت.
- دانلود CSV شماره موبایل مشتریان: داشبورد ← کاربران ← «دانلود شماره موبایل مشتریان».

## مدل‌های جدید
website: SiteSetting, Banner, FAQ — shop: ProductQuestion

API عمومی: `/website/v1/{site-setting,banners,faq}/` و `/product/v1/question/`

## ادمین جنگو (/admin/)
فارسی و راست‌چین (فقط مسیر /admin/؛ زبان کل پروژه تغییری نکرده)، فونت پیدا، تاریخ شمسی در لیست‌ها،
نام فارسی همه‌ی مدل‌ها و فیلدها، و بازگشت به داشبورد.

## اتصال به فرانت (Next.js)
بعد از `migrate` یک بار این را اجرا کنید تا سوالات متداول فعلی سایت و لینک شبکه‌های اجتماعی در دیتابیس بنشینند و از پنل قابل ویرایش شوند (چند بار اجرا کردنش امن است):
```
python manage.py load_default_content
```
دسته‌بندی سوالات متداول با تب‌های صفحه‌ی FAQ فرانت یکی شده است (مایگریشن website 0008).

## کمپین «خرید با دیجی‌کالا»
```
python manage.py load_bwdk_campaign
```
دو بنر لینک‌دار (جایگاه «بنر زیر اسلایدر»؛ دکمه به صفحه‌ی محصولات می‌رود) و مقاله‌ی «راهنمای خرید با دیجی‌کالا در من مارکت» را می‌سازد.
متن مقاله پیش‌نویس ما بر پایه‌ی راهنمای دیجی‌کالاست؛ اگر متن رسمی گوگل‌داک را دارید، از پنل ادمین ← مقالات جایگزینش کنید.

## نظرات
نظرات اسکرپ‌شده از دیجی‌کالا تگ HTML داشتند؛ حالا به متن ساده ذخیره می‌شوند و نظرات قدیمی هم هنگام `migrate` پاک‌سازی می‌شوند (مایگریشن review 0008).

## حذف‌شده
منوی سایت، صفحه‌های ثابت و اعضای خبرنامه برداشته شدند (مایگریشن website 0009).
